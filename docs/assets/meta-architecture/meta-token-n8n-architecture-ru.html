Этапы внедрения

Ключевые принципы

  • n8n управляет сценарием, backend — токенами и Graph API
  • Токены не передаются в n8n и не хранятся в workflow
  • Webhook проверяется по X-Hub-Signature-256
  • IGAA → graph.instagram.com; EAAV → graph.facebook.com
  • Секреты — в Vault/KMS; в БД только метаданные
  • Ранее раскрытые токены необходимо ротировать
