## Результат

Мастер настройки автоответов разделён на четыре шага:

1. настройка кодовых слов и публикаций;
2. настройка сообщения в Direct;
3. расширенные настройки ответов на комментарии и напоминания;
4. предпросмотр сценария в интерфейсе Instagram.

## Шаг 1. Условия запуска

- настраиваются кодовые слова `trigger_keywords`;
- выбирается точное или частичное совпадение;
- сценарий можно применять ко всем или выбранным публикациям;
- переход к сообщению выполняется кнопкой «Далее».

## Шаг 2. Сообщение в Direct

- основной ответ редактируется в поле `reply_text`;
- поддерживается двухэтапный диалог;
- текст первой кнопки хранится в `dm_quick_reply_text`;
- после первой кнопки отправляется `dm_followup_text`;
- последняя кнопка использует подпись `dm_button_text` и открывает
  `dm_button_url`;
- обе подписи кнопок редактируются;
- последняя ссылка проверяется как полный HTTP или HTTPS URL.

Кнопки общих вложений в редакторе Direct сейчас отключены. Backend endpoint
загрузки файлов сохранён для последующего включения интерфейса.

## Шаг 3. Расширенные настройки

- можно включить несколько публичных ответов на комментарии;
- один ответ выбирается случайным образом;
- в каждый ответ можно вставлять emoji;
- к каждому ответу можно прикрепить GIF;
- можно включить напоминание и выбрать задержку в минутах или часах.

Тексты и GIF хранятся в параллельных массивах:

```text
comment_replies[0]     ↔ comment_reply_gifs[0]
comment_replies[1]     ↔ comment_reply_gifs[1]
```

Подробное описание JSON находится в
[`automation-task-payload.md`](automation-task-payload.md).

## Шаг 4. Предпросмотр Instagram

Предпросмотр содержит две вкладки:

- «Сообщение» — цепочка Direct с первым ответом, быстрым ответом пользователя,
  вторым сообщением и финальной ссылочной кнопкой;
- «Комментарий» — публикация, кодовое слово пользователя, публичный ответ бота,
  GIF и строка реакций.

Интерфейс повторяет основные элементы Instagram:

- рамку телефона;
- заголовок диалога и публикации;
- аватары;
- входящие и исходящие сообщения;
- кнопки звонка и видеозвонка;
- панель комментариев;
- поле ввода и нижний индикатор телефона.

## Данные подключённого Instagram-аккаунта

Источник данных — активная строка таблицы `ig_accounts`:

| Поле | Использование |
| --- | --- |
| `display_name` | Полное имя в заголовке Direct и публикации. |
| `username` | Instagram-логин в заголовках и ответах на комментарии. |
| `profile_picture_url` | Фото профиля во всех позициях аватара. |
| `page_id` | Идентификатор профессионального Instagram-аккаунта. |
| `access_token` | Серверный запрос актуальных данных Instagram; во frontend не передаётся. |

`profile_picture_url` является URL Meta CDN и может устаревать. При запросе
`GET /api/accounts/` backend получает у Instagram актуальные `username`,
`name` и `profile_picture_url`, обновляет `ig_accounts` и возвращает свежий URL
во frontend. Если Instagram временно недоступен, используется сохранённое
значение.
